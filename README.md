# Devmentech community health files

This public repository provides the default contribution guidance, issue forms,
pull request template, and security policy for repositories in the Devmentech
organization.

Repository-specific files always take precedence over these defaults. This
repository must contain only public information. Never add credentials, private
infrastructure details, customer data, or internal contact information here.

## Included defaults

| File | Purpose |
| --- | --- |
| `CONTRIBUTING.md` | Organization-wide contribution workflow |
| `SECURITY.md` | Private vulnerability reporting guidance |
| `.github/PULL_REQUEST_TEMPLATE.md` | Review-focused pull request structure |
| `.github/ISSUE_TEMPLATE/bug.yml` | Structured bug reports |
| `.github/ISSUE_TEMPLATE/feature.yml` | Structured feature proposals |

## Precedence

When a repository defines its own community health file, GitHub uses that file
instead of the corresponding default from this repository. Repository
`README.md`, `AGENTS.md`, and contribution guides may therefore establish more
specific rules.
